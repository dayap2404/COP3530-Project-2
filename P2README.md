# Movie Ranks Project 2
A C++ project that compares Merge Sort and Heap Sort algorithms on a dataset of IMDB movie reviews.

---

## Problem Statement
People struggle to decide which movies to watch because they don’t know how they’re rated among thousands of options.  
This project sorts a large dataset of movies efficiently using sorting algorithms to make the best-rated movies easier to find.
